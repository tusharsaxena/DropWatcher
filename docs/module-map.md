# Module map — Ka0s Drop Watcher

Every non-vendored file, its responsibility, and the TOC load order. `libs/` (Ace3, LibSharedMedia,
LibDataBroker, LibDBIcon, LibCustomGlow, LibKa0s v1.75.0 (its media/icons pruned to the CLAUDE.md declaration)) and `tests/_kit/` are vendored and never edited.
