# 05: Name ideas

**Naming convention** (from NEW_ADDON.md):
- The TOC title is `Ka0s <Name>`.
- The folder name is PascalCase.
- The slash command is 2–3 lowercase letters, plus the full name in lowercase as an alias.

**Names already taken:** Loot Whisperer, LootSpotter, Loot Ratter, Loot It Forward, Beggar, Loot Radar (a
feature of ADHD BiS) and Do You Need It?. All of them are listed in `01_LANDSCAPE.md`.

None of the names below have been checked against CurseForge or Wago. **Search each one before you
commit to it.**

## Shortlist (recommendation)

1. **Ka0s Hand-Me-Ups** (`/hmu`): the most memorable. It is witty without being negative, and the slash
   command doubles as a joke.
2. **Ka0s Loot Lens** (`/ll`): the safest functional choice. It is clear in the addon list and sits well
   beside Loot History.
3. **Ka0s Fair Share** (`/fs`): warm and functional, and it describes the etiquette angle.
4. **Ka0s Dibs** (`/dib`): the shortest and punchiest, if the name is free.
5. **Ka0s Need-O-Meter** (`/nom`): the playful choice.
